# Projeto-Final (ecovida) ---DI
Aqui apresentarei minha aplicação e suas versões
# Visão geral
O EcoVida é um site de página única que reúne dicas curtas de sustentabilidade em três categorias: água, energia e lixo. A ideia é mostrar que pequenas atitudes do dia a dia, como fechar a torneira ao escovar os dentes ou tirar aparelhos da tomada, somam um grande impacto.
# Arquivos do projeto
- index.html: estrutura e conteúdo da página
- style.css: cores (paleta), layout e temas claro, escuro e alto contraste
- script.js: acessibilidade, carrossel, abas de pesquisa, login e formulário
- README.md: este documento
